# KESİŞİM

İki takımda forma giymiş futbolcuları bulur.

Bu workspace iki ayrı projeye ayrıldı:

| Proje | Klasör | GitHub | Deploy |
|---|---|---|---|
| API | [`api/`](./api) | [football-api](https://github.com/barissenturk/football-api) | Railway |
| Frontend | [`frontend/`](./frontend) | [played-both](https://github.com/barissenturk/played-both) | Vercel |

## Lokal çalıştırma

```bash
# Terminal 1 — API
cd api
npm install
npm start

# Terminal 2 — Frontend
cd frontend
npm install
npm run dev
```

Site: http://localhost:5173  
API: http://localhost:3000
